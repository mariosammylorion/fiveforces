The **Five Forces system** is a brand new personality theory developed for the primary intention of testing the limits of what a typology system can be and do. It is not so much a "true" typing system so much as it is an experiment. It was primarily designed to bring to light correlations between various existing personality typing systems, primarily MBTI, the Enneagram (particularly the instinctual subtypes), and Attitudinal Psyche. As such, it is not expected that one believes in Five Forces like these other systems. Rather, it is a fun "break" from these more constrained systems, and will primarily aid in fictional character typing exercises.

# Inspirations

The main inspirations for the Five Forces system come from MBTI and Attitudinal Psyche. MBTI uses Intuition, Sensing, Feeling, and Thinking to create a system which paints a picture into how the mind operates in a "cognitive function stack." Attitudinal Psyche (and its parent Psychosophy) also uses a sort-of stack, but instead displays how people's attitudes are towards Emotion, Logic, Physics, and Volition. The Five Forces themselves draw heavy inspiration from these aspects while also being their own separate entities.

- **Logic** is a derivative of MBTI's Thinking (particularly Introverted Thinking) and AP's Logic.
- **Imagination** draws inspiration from MBTI's Intuition and AP's Emotion and Volition.
- **Optimization** is a separate entity inspired partly by AP's Volition and Physics with qualities from MBTI's Extroverted Thinking.
- **Reality** possesses qualities of AP's Physics and Logic with MBTI's Sensing (particularly Introverted Sensing).
- **Valuation** is a derivative of MBTI's Feeling and AP's Emotion, with a little bit of AP's Volition.

In addition, the five positions and 25 atoms mirror AP's positioning system, drawing inspiration from the "trust" system of the elements. This all sheds into light that while Five Forces is not exactly an original system, it is a valid framework for dissecting the human psyche.
